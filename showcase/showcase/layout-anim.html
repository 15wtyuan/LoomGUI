布局动画验收#10 · 6 项
layout 动画 · width / height / flex-grow / box-shadow
同域端点动画（px↔px / vw↔vw）· transition + keyframes + C# TweenBuilder 三通道 · 验收标准逐项写在各节描述里
1 · 折叠面板（transition height 0↔200px）
验收：点「展开」按钮，面板高度应在约 0.4 秒内逐帧增高至 200px（无跳变；一次性瞬间到位即失败）；再点「收起」平滑降回 0。终点精确 200px（与右侧 200px 参照条同高）。
↑ 上横条：320px 参照宽 · 右竖条：200px 参照高
2 · 充能进度条（@keyframes width 0→360px 循环）
验收：蓝色填充条应从左端平滑增长到满宽（约 2.4 秒一轮），到头后从 0 重新开始、无限循环。静止不动 / 一次性跳到满宽 / 循环中断即失败。宽度走的是布局通道（不是 scaleX）。
3 · 侧栏收起（transition flex-grow 1↔0）
验收：点「收起侧栏」后紫色侧栏份额应在约 0.5 秒内平滑收缩至零宽，同时蓝色主区平滑扩张占满整行（兄弟份额换手，无跳变）；再点恢复。中段两块宽度都在连续变化即通过。
4 · 响应式面板（transition width 50vw↔80vw）
验收：点「拉宽」按钮，绿色面板应在约 0.6 秒内平滑增宽；端点是视口百分比——终端宽度应≈设计宽 1920 的 80%（1536px）。再点回 50%（960px）。宽度平滑过渡即通过。
5 · box-shadow 过渡（透明淡入 vs inset 离散）
验收：左卡悬停——第二层青色大阴影应从透明**平滑淡入**（约 0.5 秒，颜色渐现非瞬间弹出；瞬间弹出即失败），移出淡出。右卡悬停——外阴影切到 inset 是**离散跳变**（浏览器同语义：配对 inset 不匹配不插值），瞬间切换即正确行为、出现渐变反而是 bug。
左：单层 → 双层（淡入）悬停看青色阴影渐现
右：outer → inset（离散）悬停看瞬间切换
6 · C# TweenBuilder.Height（运行时 API 摆台）
验收：点「C# 动画」按钮，由 driver 代码提交 TweenBuilder（Height 60→220px，0.6s cubic-out）驱动面板增高——视觉节奏应与 #1 的 CSS transition 同类（平滑、终点精确 220px），非跳变。再点回落。终点与右侧 220px 参照条同高。
↑ 右竖条：220px 终点参照
