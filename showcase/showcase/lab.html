16 · 缓动全集 / transform-origin / per-stop timing（#9 动画终态基建）
判据只认肉眼看得见的信号：① 缓动画廊八行，圆点全部 1.6 秒循环左→右，行间差异一眼可判——linear 匀速（对照基准）；ease-out-bounce 到右端弹跳回落数次；ease-out-elastic 到右端弹簧式振几下；cubic-bezier 末段冲出轨道右缘再贴回；step-end 全程钉在左端、循环末尾瞬移右端；step-start 相反（起点即瞬移右端、保持到底）；shorthand·elastic / shorthand·bezier 两行须与各自的 elastic / bezier 行完全同步（同起同落同弹——不同步即 shorthand 位声明丢失）。② origin 对照——蓝条绕几何中心旋转（扫出圆环），金条左上角钉死不动、整条像圆规甩转。③ per-stop timing——红条去程匀速、回程末端冲过左端界再弹回（同一条动画两段节奏肉眼不同）。④ 混合百分比——浅蓝条从轨道右端外滑入、匀速横穿、滑出左端外完全消失，循环；条不动或穿得不对称（半宽量级不对）即失败。⑤ runtime TweenBuilder——点「播放 tween」：红块 0.5 秒右滑贴轨道右段、再 0.5 秒原路滑回，跑满读数变「tween 完成」；只滑一趟不回、读数停在「播放中」即失败；可重复点击重放。

18 · 换行控制全集（white-space 五值 / word-break / overflow-wrap / text-wrap / kinsoku 禁则 · #73）
判据（对照盒右缘边框线，一眼可辨）：① nowrap——整段单行、文字冲出盒右缘（折成多行即失败）。② pre——文本保持源码换行结构且长行不折（溢出右缘）；pre-wrap——同源文本但长行折回盒内（溢出即失败）；pre-line——换行保留、第二行行首无缩进空格（源码缩进被折叠；显示缩进即失败）。③ 禁则——「kinsoku 禁则」盒内任何一行的行首不得出现句号/逗号/闭括号（盒宽已调到朴素断行必出孤悬句读；行首见标点即失败）。④ keep-all——中文无空格串单行溢出（折行即失败，CJK 词内不断）；break-all——长英文串折成多行填满盒内（单行溢出即失败）；同串在「对照 normal」盒单行溢出。⑤ break-word——同串 normal 对照溢出、break-word 盒折行入盒。⑥ text-wrap:nowrap——双空格保留（词间空隙明显宽于单空格）、源换行仍断行、长行不折（溢出）。

20 · 光标 affordance（cursor · #93）
验收（Unity PlayMode，肉眼判据）：① 悬停「可点按钮」——软件指针变手型，移出盒外复原系统箭头（UA 默认：pressable 控件悬停给手型）；悬停按钮**文字**同样手型（命中细化到文字子节点后上溯宿主控件）。② 悬停「禁用按钮」——保持系统箭头不变形（含其文字区）。③ 悬停「地图节点」——手型（div + cursor:pointer：作者声明把非控件可点区标为手型；与「普通 div」盒对照——普通 div 保持箭头，手型只能来自作者声明，与①的手型同为一只属预期）。④ 悬停「压制按钮」——保持系统箭头（button + cursor:default：作者声明压过 UA 手型）。⑤ 悬停「自绘区」——指针消失（cursor:none），移出复原。预览侧浏览器原生渲染 cursor，天然正确。
